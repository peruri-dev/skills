## grooming 0.4.0

### Diubah

- Skill `exam-prd-design`: format isi komentar temuan diperbarui — narasi temuan lebih netral (fakta yang terlihat, lalu acuan sisi sebelah, lalu implikasinya), pertanyaan berupa bullet di bawah heading `Pertanyaan untuk PO` (komentar Confluence) atau `Pertanyaan untuk desainer` (komentar Figma), baris `cc:` men-tag PIC sisi terkait (pembuat halaman PRD untuk Confluence, desainer untuk Figma — dicari otomatis dari API, pengguna ditanya sekali per batch kalau tidak ketemu), dan watermark `[Generated by AI Assistant]` sebagai baris terakhir. Tanda markdown tidak dipakai karena komentar Confluence/Figma tidak merender markdown; baris acuan file laporan dihapus dari isi komentar.

## grooming 0.3.0

### Ditambahkan

- Skill `exam-prd-design`: opsi memposting komentar atas temuan yang pengguna pilih setelah laporan batch ditulis — komentar inline di PRD Confluence pada teks persis yang menjadi bukti temuan, dan komentar terpaku pada node layar Figma yang menjadi temuan. Temuan tanpa anchor di satu sisi hanya dikomentari di sisi satunya; tawaran sekali per batch; isi komentar ringkas dengan acuan ke file laporan.

## grooming 0.2.0

### Ditambahkan

- Skill `boil-api-contract`: draf kontrak API dan kartu technical grooming (Backend API + Frontend) per story Jira, dengan gating dari temuan `exam-prd-design`, cek reuse ke OpenAPI backend, dan push opsional ke FigJam.
- Script `openapi_index.py` (indeks endpoint, katalog kode error, statistik konvensi, `--exclude` untuk uji) beserta fixture dummy dan test regresi. Parameter di level path digabung dengan level operasi, body multipart di-resolve dari `$ref` dan menghormati `required`, `$ref` ke semua komponen lokal (`#/components/parameters/`, dll.) ikut di-resolve, dan file yang tidak ada memberi pesan jelas tanpa traceback.
- Template konvensi API per project (`references/konvensi-template.md`).
